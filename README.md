# Tazawoudou_Sixaar

Site web du dahira **Tazawoudou Sixaar** : cellules, bibliothèque de Khassaïdes et Kaggu en PDF, événements, commissions, cotisations.

## Structure
- `index.html` : la page du site
- `style.css` : les couleurs et le design
- `data.js` : **le seul fichier à modifier** (cellules, PDF, événements, numéros)
- `script.js` : le code qui construit les pages
- `pdf/` : tes fichiers PDF (kaggu.pdf, etc.)

## Mise en ligne
GitHub → Settings → Pages → Branch `main` / dossier `/ (root)` → Save.
